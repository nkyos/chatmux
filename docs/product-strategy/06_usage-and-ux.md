# ユーザー体験とワークフロー

## 基本ワークフロー

chatmux は**常駐アプリ**。ここが操作の起点になる。

```
1. ターミナルで chatmux を起動（常駐）
2. chatmux 上から claude セッションを起動
3. 複数セッションを切り替えながら作業
4. 別のセッションで返信が来たら通知で気づく
5. 一覧から選んで切り替え
```

## セッション一覧のこだわり — タブとの差別化

### 情報密度
各セッションに以下を表示し、**切り替えなくても状況を把握**できる:
- **状態アイコン** — ⚠️ waiting / 🔴 replied / ⏳ working / 💤 idle
- **プロジェクト名 + 最終更新時間**
- **タスクラベル** — 何を頼んだか（最初のメッセージから自動生成 or 手動命名）
- **最終メッセージのプレビュー** — 開かなくても何が起きたか見える
- **Git ブランチ + コスト**

### スマートソート
注意が必要なものが自動的に上に来る:
1. ⚠️ ユーザー入力待ち（permission prompt 等）
2. 🔴 返信あり・未読
3. ⏳ 作業中（新しいものから）
4. 💤 idle

### サマリーバー
全セッションの状況を一行で俯瞰:
```
⚠️1 🔴2 ⏳1 💤3 | Total: $1.23
```

## 操作

### セッション管理
- **起動 `n`**: 新規セッション作成（プロジェクト選択 → claude 起動）
- **切替 `j/k`**: セッション選択
- **フォーカス `Enter`**: ターミナルビューに切替、キー入力が claude に行く
- **戻る `Esc`**: サイドバーに戻る
- **セッション対象**: `chatmux` 経由で起動したもののみ管理

### クイックアクション（セッションを開かずに操作）
- **`y`** — permission prompt に Yes を送る
- **`d`** — セッション削除
- **`e`** — エディタを開く
- **`r`** — タスク名を変更

### 通知
- **OS ネイティブ通知**: replied / waiting 時に macOS 通知センターへ
- **TUI 内バッジ**: セッション一覧の状態アイコン + 未読表示

## セッションの状態

| 状態 | 意味 | 表示 | 通知 |
|------|------|------|------|
| waiting | ユーザー入力待ち（permission等） | ⚠️ | OS通知 |
| replied | エージェントが応答済み・未読 | 🔴 | OS通知 |
| working | エージェントが処理中 | ⏳ | — |
| idle | 会話が止まっている | 💤 | — |

## まだ対象外

- 複数セッションの同時表示（ペイン分割）
- chatmux 外で起動した既存セッションの取り込み
- エージェント間のオーケストレーション
