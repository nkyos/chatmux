# Core — chatmux の核心

## 信念 (Belief)

> **コーディングエージェントは「使い捨てのコマンド」ではなく「並行する会話」である。**

Claude Code、Cursor、Copilot Chat、Aider… コーディングエージェントとのやりとりは、
もはや単発のコマンド実行ではない。複数のタスクを並行して走らせ、
途中で確認し、返答を待ち、また指示を出す — これは**チャット**そのものである。

しかし、現状ではこれらのセッションを管理する統一的な方法がない。

## 洞察 (Insight)

> **コーディングエージェントのセッションには「チャットクライアント」が必要だ。**

LINE、Slack、Discord が複数の会話を1つのウィンドウで管理できるように、
コーディングエージェントの複数セッションも同じように管理できるべきだ。

- 左にセッション一覧、右に会話内容
- 新しい返信が来たら通知
- どのセッションが待ち状態か、作業中か、完了したか一目でわかる

## Core Statement

> **chatmux は、複数のコーディングエージェントセッションを
> 統一的に管理・閲覧・操作するためのチャットクライアントである。**
