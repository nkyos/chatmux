# What — chatmux は何をするのか

## プロダクトの定義

chatmux は、複数のコーディングエージェントセッションを統一的に管理するチャットクライアント。
LINE / Slack / Discord のように、セッション一覧・会話表示・通知を1つのインターフェースで提供する。

## コア体験

1. **セッション一覧**: 走っているエージェントセッションが一覧で見える（状態付き）
2. **セッション起動**: chatmux 上から新しいエージェントセッションを起動できる
3. **セッション表示**: 選択したセッションのターミナル画面 or 会話内容を見られる
4. **通知**: エージェントから返信が来たらユーザーに知らせる
5. **入力**: セッションに対してメッセージ・操作を送れる

## 対象エージェント

- **Phase 1**: Claude Code
- **将来**: OpenAI Codex、その他

## セッションの状態モデル

```
起動 → 作業中 → ユーザー入力待ち → 作業中 → ... → 完了/idle
         ↑                                        |
         └────── resume ──────────────────────────┘
```

各セッションは以下のいずれかの状態:
- **作業中** (working) — エージェントが処理中
- **入力待ち** (waiting) — ユーザーの確認・入力を待っている ← 通知対象
- **返信あり** (replied) — エージェントが応答済み、未読 ← 通知対象
- **idle** — 会話が止まっている
- **完了** (done)

## 何をしないか (Non-Goals) — 初期段階

- エージェントの実行環境そのものの提供
- エージェント間の連携・オーケストレーション
- 会話内容の編集・改変
