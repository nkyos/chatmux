# PoC 計画

## ゴール

最小限の動作で「chatmux のコア体験」を検証する。

> chatmux を起動 → claude セッションを作成 → ターミナル画面が見える →
> キー入力で操作できる → 別セッションに切り替えられる

## スコープ

### やること
- [x] Go プロジェクトのセットアップ
- [ ] tmux クライアント（new-session, capture-pane, send-keys, kill-session）
- [ ] セッションマネージャ（作成、一覧、削除）
- [ ] TUI: セッション一覧サイドバー（名前、プロジェクト、最終更新時間）
- [ ] TUI: ターミナルビュー（capture-pane の出力表示）
- [ ] TUI: キー入力の tmux 転送
- [ ] TUI: プロジェクト選択（過去プロジェクト一覧 + filepicker でカスタムパス）
- [ ] 基本的なキーバインド（セッション切替、新規作成）

### やらないこと（PoC 後）
- JSONL 監視による状態検知
- OS ネイティブ通知
- セッション状態バッジ（working/replied/idle）
- 設定ファイル
- エディタ連携

## PoC の操作イメージ

```
$ chatmux

┌─ Sessions ─────┐ ┌─ Terminal ──────────────────┐
│                 │ │                              │
│  (empty)        │ │  Press 'n' to new session    │
│                 │ │                              │
│                 │ │                              │
│                 │ │                              │
│                 │ │                              │
└─────────────────┘ └──────────────────────────────┘

  n: new session  q: quit  j/k: select  Enter: focus

→ 'n' を押すとプロジェクトディレクトリを聞かれる
→ claude が tmux セッション内で起動
→ 左にセッション、右に claude の画面
→ Enter でターミナルにフォーカス → キー入力が claude に行く
→ Esc でサイドバーに戻る
→ j/k で別セッションに切替
```

## 実装順序

1. **tmux クライアント** — tmux 操作の薄いラッパー
2. **セッションマネージャ** — セッションのライフサイクル管理
3. **TUI 骨格** — Bubble Tea の基本構造 + 左右分割レイアウト
4. **サイドバー** — セッション一覧表示
5. **ターミナルビュー** — capture-pane + 定期リフレッシュ
6. **キー入力転送** — フォーカス制御 + send-keys
