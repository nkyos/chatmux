# ロードマップ

## Phase 0: PoC ✅

コア体験の検証。「chatmux で claude セッションを管理できる」を動くもので確認。

- [x] tmux バックエンド + Bubble Tea TUI
- [x] セッション作成（プロジェクト選択: 過去一覧 + filepicker）
- [x] セッション一覧 + 切替
- [x] ターミナル画面表示（capture-pane）
- [x] キー入力転送（send-keys）

## Phase 1: 実用レベル ✅

PoC を日常使いできるレベルに引き上げる。

- [x] **JSONL 監視**: Claude Code の会話履歴を監視して状態を自動判定
  - working / replied / idle の検知（2秒間隔、mtime キャッシュ付き）
- [x] **OS ネイティブ通知**: replied 時に macOS 通知センターへ通知
  - terminal-notifier 使用（フォールバック: osascript）
- [x] **TUI 内バッジ**: セッション一覧に状態アイコン・未読バッジ
- [x] **最終返信時間**: セッション一覧に「3m ago」等のタイムスタンプ表示
- [x] **セッション永続化**: chatmux を閉じて再起動しても tmux セッションが残る
  - q でデタッチ（セッション保持）、Q で全終了
  - 起動時にリストア or フレッシュスタートを選択
- [x] **エディタ連携**: 選択中セッションのプロジェクトを `$EDITOR` で開く（`e` キー）
- [x] **設定ファイル**: `~/.config/chatmux/config.toml` でエディタ・通知・表示設定

## Phase 2: 磨き込み ✅

日常使いで出てくる不満を解消。

- [x] **セッション検索・フィルタ**: `/` キーでプロジェクト名・ステータス等で絞り込み
- [x] **セッション名のカスタマイズ**: `r` キーで表示名（task_label）を編集
- [x] **セッションのソート**: `s` キーでステータス順・最終更新順・手動順を切替
- [x] **マウス操作**: クリック選択・ドラッグ・スクロール対応
- [x] **通知のカスタマイズ**: config.toml で有効/無効・対象ステータス・サウンド設定
- [x] **セッション履歴**: `h` キーで終了済みセッション一覧、Enter で再開
- [x] **テーマ**: config.toml でカラースキーム設定（名前付き色 + hex RGB）

## Phase 3: マルチエージェント（現在）

Claude Code 以外のエージェントへの対応。

- [ ] **エージェント種別の表示**: セッション一覧にアイコン等で区別
