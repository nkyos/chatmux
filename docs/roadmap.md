# ロードマップ

## Phase 0: PoC（現在）

コア体験の検証。「chatmux で claude セッションを管理できる」を動くもので確認。

- tmux バックエンド + Bubble Tea TUI
- セッション作成（プロジェクト選択: 過去一覧 + filepicker）
- セッション一覧 + 切替
- ターミナル画面表示（capture-pane）
- キー入力転送（send-keys）

## Phase 1: 実用レベル

PoC を日常使いできるレベルに引き上げる。

- [ ] **JSONL 監視**: Claude Code の会話履歴を監視して状態を自動判定
  - working / replied / waiting / idle の検知
- [ ] **OS ネイティブ通知**: replied / waiting 時に macOS 通知センターへ通知
- [ ] **TUI 内バッジ**: セッション一覧に状態アイコン・未読バッジ
- [ ] **最終返信時間**: セッション一覧に「3m ago」等のタイムスタンプ表示
- [ ] **セッション永続化**: chatmux を閉じて再起動しても tmux セッションが残る
- [ ] **エディタ連携**: 選択中セッションのプロジェクトを `$EDITOR` で開く
- [ ] **設定ファイル**: `~/.config/chatmux/config.toml` でキーバインド・表示設定

## Phase 2: 磨き込み

日常使いで出てくる不満を解消。

- [ ] **セッション検索・フィルタ**: プロジェクト名やステータスで絞り込み
- [ ] **セッション名のカスタマイズ**: 「auth修正」「テスト追加」等の表示名
- [ ] **セッションのソート**: 最終更新順、状態順、手動順
- [ ] **マウス操作**: セッション一覧のクリック選択
- [ ] **通知のカスタマイズ**: 通知する状態の選択、サウンド設定
- [ ] **セッション履歴**: 終了済みセッションの一覧・再開
- [ ] **テーマ**: カラースキームの設定

## Phase 3: マルチエージェント

Claude Code 以外のエージェントへの対応。

- [ ] **アダプタインターフェース**: エージェントごとの接続方式を抽象化
- [ ] **OpenAI Codex 対応**: Codex CLI のアダプタ実装
- [ ] **エージェント固有の状態検知**: 各エージェントの出力パターンに応じた判定
- [ ] **エージェント種別の表示**: セッション一覧にアイコン等で区別

## Phase 4: 発展

ユーザーフィードバック次第で検討。

- [ ] **ペイン分割**: 複数セッションの同時表示
- [ ] **スクリプティング API**: 外部ツールとの連携（パイプ、フック）
- [ ] **セッショングループ**: プロジェクト単位でのセッションまとめ
- [ ] **AI 要約**: セッションの進捗をワンラインで要約表示
- [ ] **チーム共有**: セッション情報のエクスポート・共有
- [ ] **パッケージ配布**: Homebrew, go install 等
